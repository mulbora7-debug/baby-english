# Baby English Fairy Tales

3~4세 아이가 좋아하는 공주 동화를 영어로 듣고 놀 수 있는 태블릿용 웹앱입니다.

## 이야기

- 신데렐라: 10장
- 백설공주: 10장
- 인어공주: 10장

각 이야기는 처음부터 결말까지 이어지는 유아용 완결판입니다. 고전의 큰 줄거리를
바탕으로 새로 작성했으며 특정 애니메이션·영화의 대사나 이미지를 사용하지 않습니다.

## 한 장의 학습 흐름

1. 영어·한국어 이야기 듣기
2. 캐릭터 질문 듣고 핵심 문장 말하기
3. 그림에서 오늘의 단어 찾기
4. 짧은 첫소리 리듬 듣기
5. 별을 받고 다음 장으로 이동

키보드 입력이나 읽기 능력을 요구하지 않으며, 큰 그림과 음성 버튼으로 진행합니다.
완료한 장은 브라우저의 `localStorage`에 저장됩니다.

## 콘텐츠 원칙

- 한 화면에는 한 가지 활동만 보여줍니다.
- 틀린 답에는 벌점이나 강한 실패 표시를 사용하지 않습니다.
- 문법 규칙을 설명하지 않고 짧은 문장 덩어리를 이야기 안에서 반복합니다.
- 모든 이야기에는 영어와 한국어 음성을 함께 제공합니다.
- 스토리에는 엄마, 어머니, mother, mom 등의 소재나 등장인물을 사용하지 않습니다.
