# Baby English

3.5세 아이를 위한 브라우저 기반 영어 학습 프로그램입니다.

## 학습 흐름

1. 짧은 대화 듣기
2. 거북이 버튼으로 천천히 다시 듣기
3. 챕터 주요 단어 복습
4. 그림 퀴즈
5. 별 보상 및 완료 기록

## 동화 영어

처음 화면에서 신데렐라 또는 인어공주 이야기를 선택할 수 있습니다.

- 신데렐라: 친절, 옷, 시간, 물건 찾기를 주제로 한 4개 에피소드
- 인어공주: 바다 생물, 색깔, 친구, 감정을 주제로 한 4개 에피소드

각 에피소드는 짧은 이야기 듣기, 오늘의 한마디, 단어 듣기, 그림 퀴즈로 구성됩니다.
영어 이야기 전체 듣기와 한국어 이야기 전체 듣기를 각각 지원합니다.

오늘의 영어는 태블릿의 날짜를 기준으로 매일 다른 수업을 보여줍니다. 같은 날에는
항상 같은 수업이 유지되며, 다음 날 사이트를 다시 열면 다음 수업으로 자동 전환됩니다.
단어 카드를 누르면 단어를 천천히 두 번 읽은 뒤 짧은 예문을 들려줍니다.
완료 날짜와 연속 학습 기록은 브라우저의 `localStorage`에 저장됩니다.

## 콘텐츠 원칙

- 음성이 제공되는 학습 항목에는 영어 듣기와 한국어 듣기를 함께 제공합니다.
- 스토리에는 엄마, 어머니, mother, mom 등의 소재나 등장인물을 사용하지 않습니다.

## 실행 방법

### 가장 간단한 방법

`index.html` 파일을 Chrome 또는 Edge에서 엽니다. 별도 설치나 빌드 과정은 필요하지 않습니다.

### VS Code Live Server 사용

1. VS Code에서 `baby_english` 폴더를 엽니다.
2. Live Server 확장을 설치합니다.
3. `index.html`을 우클릭합니다.
4. `Open with Live Server`를 선택합니다.

## Windows 폴더 위치

프로젝트 폴더 전체를 다음 위치에 두면 됩니다.

```text
E:\CODE PROJECT\baby_english
```

최종 구조:

```text
baby_english/
├── index.html
├── styles.css
├── app.js
└── README.md
```

## 사용 환경

- 권장 브라우저: 최신 Chrome, Edge 또는 Safari
- 권장 화면: 태블릿 가로 모드
- 갤럭시 탭 E 8.0의 1280×800 가로 화면에서는 앱 프레임이 화면 높이에 고정되며,
  긴 동화 콘텐츠만 카드 내부에서 스크롤됩니다.
- 인터넷 연결: 필요 없음
- 서버 및 패키지 설치: 필요 없음
- 음성: 운영체제와 브라우저에 설치된 Web Speech API 음성을 사용하므로 기기마다 목소리가 다를 수 있습니다.

## 참고

브라우저가 음성 재생을 막는 경우 화면의 듣기 버튼을 한 번 직접 누르면 재생이 시작됩니다. 학습 완료 기록을 초기화하려면 브라우저 개발자 도구에서 사이트의 로컬 저장소 항목 `babyEnglishCompleted`를 삭제하세요.

## GitHub Pages 배포

이 프로젝트는 별도의 빌드 과정이 없는 정적 웹앱입니다. GitHub 저장소의
`main` 브랜치 루트에서 바로 GitHub Pages로 공개할 수 있습니다.

GitHub 저장소의 `Settings > Pages`에서 다음과 같이 선택합니다.

```text
Source: Deploy from a branch
Branch: main
Folder: / (root)
```

배포가 완료되면 다음 형태의 HTTPS 주소로 태블릿에서 접속할 수 있습니다.

```text
https://사용자이름.github.io/baby-english/
```
